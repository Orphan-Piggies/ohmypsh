# 🥜 oh-my-pistachio (omp)

> Terminalınızı qovrulmuş bir backend cənnətinə çevirin. NTT layihəsidir.

## 🚀 Xüsusiyyətlər
- **Duzlu Sintaksis**: Kodlarınız avtomatik olaraq dəniz duzu ilə qorunur.
- **Qabıq Təhlükəsizliyi**: `sudo` yazmaq bəs etmir, klaviaturaya fiziki olaraq 9.8 Nyuton güclə vurmalısınız.
- **Antep Rejimi**: Terminal piksellərini maksimum yaşıl rəngə kökləyir.

## 🛠 Quraşdırma
```bash
curl -fsSL https://githubusercontent.com | psh
```
